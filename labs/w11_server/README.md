# เซิร์ฟเวอร์ MCP ประจำรายวิชา (แล็บสัปดาห์ที่ 11)

เซิร์ฟเวอร์ MCP ตัวอย่างที่เปิดเผย 3 tools, 2 resources และ 1 prompt
**เซิร์ฟเวอร์ตัวเดียวนี้ใช้ได้กับไคลเอนต์ทุกตัวที่รองรับ MCP** โดยไม่ต้องแก้โค้ด

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `tools.py` | ตรรกะล้วน ไม่ import `mcp` จึงทดสอบด้วย Python ธรรมดาได้ |
| `server.py` | ชั้นโปรโตคอลบาง ๆ ที่ลงทะเบียนฟังก์ชันจาก `tools.py` เข้ากับ MCP |

การแยกแบบนี้คือแนวปฏิบัติที่ควรทำกับเซิร์ฟเวอร์ MCP ทุกตัว: แกนที่ทดสอบได้ + ชั้นโปรโตคอลที่บาง

## ความสามารถที่เปิดเผย

**Tools** (โมเดลเป็นผู้เรียก)

- `search_course(query, max_results)` ค้นเนื้อหาประมวลรายวิชา (ค้นด้วยคำหลัก ดูข้อจำกัดข้างล่าง)
- `convert_energy(value, unit)` แปลงพลังงานเป็น eV
- `get_week_topic(week)` หัวข้อบรรยายของสัปดาห์ที่ระบุ

**Resources** (แอปพลิเคชันเป็นผู้ดึง)

- `course://syllabus`
- `course://week/{week}`

**Prompts** (ผู้ใช้เป็นผู้เลือก)

- `review_report(text)`

## รัน

```bash
pip install "mcp[cli]"

npx @modelcontextprotocol/inspector python server.py      # ทดสอบผ่าน UI
```

## ต่อเข้ากับไคลเอนต์

ไฟล์ตั้งค่ามีรูปแบบเกือบเหมือนกันทุกไคลเอนต์ ให้แทนที่ `/ABS/PATH` ด้วยพาธเต็มของไดเรกทอรีนี้

```json
{
  "mcpServers": {
    "course-tools": {
      "command": "python",
      "args": ["/ABS/PATH/labs/w11_server/server.py"]
    }
  }
}
```

| ไคลเอนต์ | ที่อยู่ไฟล์ตั้งค่า |
| --- | --- |
| Claude Code | `.mcp.json` ในโปรเจกต์ หรือ `claude mcp add course-tools -- python /ABS/PATH/server.py` |
| Gemini CLI | `~/.gemini/settings.json` |
| Cline / Roo Code | ตั้งค่าในส่วนขยายของ VS Code |
| Codex CLI, Qwen Code | ไฟล์ตั้งค่าของเครื่องมือนั้น |

## ข้อจำกัดที่รู้อยู่แล้วของ `search_course`

`search_course` ค้นด้วย **คำหลัก** ล้วน ๆ (TF-IDF บน character n-gram)
และ `README.md` ของรายวิชาเขียนเป็นภาษาอังกฤษเกือบทั้งหมด
คำค้นภาษาไทยจึงมักไม่ตรงกับอะไรเลย และคืนหัวข้อที่ไม่เกี่ยวข้องออกมา

```bash
python -c "import tools; print(tools.search_course('Grading Assessment')[:80])"   # ได้ผลดี
python -c "import tools; print(tools.search_course('เกณฑ์การให้คะแนน')[:80])"      # ได้ผลแย่
```

นี่ไม่ใช่บั๊ก แต่คือข้อจำกัดของการค้นแบบคำหลัก และเป็นเหตุผลที่ต้องมี
**embedding เชิงความหมาย** ซึ่งเป็นเนื้อหาของสัปดาห์ที่ 10
ลองแก้ปัญหานี้ดูได้โดยนำ retriever จาก [`../w10_rag.ipynb`](../w10_rag.ipynb)
มาใส่แทน แล้ววัดผลด้วยชุดคำถามภาษาไทย

## ข้อควรระวังด้านความปลอดภัย

เซิร์ฟเวอร์นี้ **อ่านอย่างเดียว** จึงปลอดภัยที่จะให้ทำงานอัตโนมัติ
ถ้าคุณเพิ่มเครื่องมือที่เขียนไฟล์ ส่งข้อความ หรือเรียก API ภายนอก ต้อง

1. ให้ไคลเอนต์ขออนุมัติจากผู้ใช้ก่อนทุกครั้ง
2. จำกัดขอบเขต เช่น เขียนได้เฉพาะในไดเรกทอรีที่กำหนด
3. จำไว้ว่า **ผลลัพธ์ที่คืนกลับไปคือข้อมูล ไม่ใช่คำสั่ง** ถ้าเนื้อหามาจากแหล่งที่ควบคุมไม่ได้
   ให้ถือว่าอาจมีการฉีดพรอมป์ตแฝงอยู่
