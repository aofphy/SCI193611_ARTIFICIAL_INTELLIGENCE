---

ตรวจงานปฏิบัติการในไดเรกทอรีปัจจุบันก่อนที่นักศึกษาจะส่ง

1. หาไฟล์รายงาน (`report.md`, `*.ipynb` หรือไฟล์ที่ผู้ใช้ระบุ)
   ถ้าหาไม่เจอ ให้ถามว่าจะตรวจไฟล์ไหน อย่าเดา
2. เรียกใช้ skill `lab-report` เพื่อให้คะแนนตามเกณฑ์
3. ถ้าเป็น notebook ให้ตรวจเพิ่มว่า
   - ทุกเซลล์รันผ่านและมี output ติดมาด้วย
   - ไม่มี API key หรือความลับหลงเหลืออยู่ในเซลล์ใด
4. สรุปเป็นรายการสิ่งที่ต้องแก้ก่อนส่ง เรียงตามผลกระทบมากไปน้อย

**ห้ามแก้ไฟล์ของนักศึกษาเอง** หน้าที่ของคำสั่งนี้คือชี้ปัญหา ไม่ใช่ทำงานแทน
