# ตรวจรายงานปฏิบัติการ SCI19 3611

## ขั้นตอน

1. อ่านรายงานทั้งฉบับก่อน อย่าเพิ่งให้คะแนนจากส่วนใดส่วนหนึ่ง
2. รัน `python scripts/check_report.py <ไฟล์>` เพื่อตรวจสิ่งที่ตรวจด้วยโปรแกรมได้
   (หัวข้อที่ต้องมี ความยาว จำนวนการอ้างอิง แถลงการณ์การใช้ AI)
3. ให้คะแนนแต่ละเกณฑ์ 0 ถึง 5 ตาม `reference/rubric.md`
4. สรุปด้วยข้อเสนอแนะที่ **ทำได้จริง** 3 ข้อ เรียงตามผลกระทบมากไปน้อย

## รูปแบบผลลัพธ์

```
| เกณฑ์ | คะแนน | เหตุผล |
| --- | --- | --- |
| ระเบียบวิธี | 4/5 | ... |
...
รวม: xx/20

ข้อเสนอแนะ
1. ...
```

## ข้อควรระวัง

- **อย่าให้คะแนนจากความยาว** รายงานสั้นที่มีหลักฐานครบ ดีกว่ารายงานยาวที่ไม่มี
- ถ้ารายงานไม่มีแถลงการณ์การใช้ AI ให้หักเกณฑ์ "การอ้างอิง" และระบุไว้ชัดเจน
- ถ้าพบตัวเลขที่ไม่มีที่มา ให้ถามหาที่มา อย่าสันนิษฐานว่าถูก
- รายละเอียดเกณฑ์เต็มอยู่ใน `reference/rubric.md` อ่านเมื่อคะแนนอยู่ระหว่างสองระดับ
