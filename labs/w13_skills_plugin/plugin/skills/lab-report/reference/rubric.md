# เกณฑ์การให้คะแนนรายงานปฏิบัติการ (รวม 20 คะแนน)

ไฟล์นี้เป็น **ระดับที่ 3** ของการเปิดเผยแบบขั้นบันได:
เอเจนต์จะอ่านก็ต่อเมื่อ `SKILL.md` บอกให้อ่าน จึงไม่กินบริบทตอนที่ไม่ได้ใช้

## 1. ระเบียบวิธี (5 คะแนน)

| คะแนน | เกณฑ์ |
| --- | --- |
| 5 | ระบุขั้นตอน พารามิเตอร์ เวอร์ชันไลบรารี และ seed ครบจนทำซ้ำได้โดยไม่ต้องถาม |
| 4 | ครบเกือบหมด ขาดรายละเอียดเล็กน้อยที่เดาได้ |
| 3 | อธิบายภาพรวมได้ แต่ทำซ้ำไม่ได้ถ้าไม่ถามเพิ่ม |
| 2 | อธิบายลอย ๆ ไม่มีพารามิเตอร์ |
| 0 ถึง 1 | ไม่มีส่วนระเบียบวิธี หรือขัดแย้งกับผลที่แสดง |

## 2. ผลลัพธ์และหลักฐาน (5 คะแนน)

| คะแนน | เกณฑ์ |
| --- | --- |
| 5 | มีตาราง กราฟ หรือตัวเลขจริงจากการรัน พร้อมระบุเงื่อนไขการวัด |
| 4 | มีผลจริง แต่ขาดเงื่อนไขบางอย่าง เช่น จำนวนรอบที่รัน |
| 3 | มีผลบางส่วน ผสมกับการกล่าวอ้างที่ไม่มีหลักฐาน |
| 2 | เล่าว่าได้ผลอย่างไร แต่ไม่มีตัวเลข |
| 0 ถึง 1 | ไม่มีผล หรือผลที่แสดงไม่ตรงกับที่อ้าง |

## 3. การอ้างอิงและความซื่อสัตย์ (5 คะแนน)

| คะแนน | เกณฑ์ |
| --- | --- |
| 5 | อ้างอิงครบทุกแหล่ง ตรวจสอบได้จริง และมีแถลงการณ์การใช้ AI ที่ชัดเจน |
| 4 | อ้างอิงครบ แต่แถลงการณ์การใช้ AI กว้างเกินไป |
| 3 | อ้างอิงบางส่วน หรือไม่มีแถลงการณ์การใช้ AI |
| 2 | อ้างอิงไม่ครบและตรวจสอบไม่ได้ |
| 0 | พบการอ้างอิงที่ไม่มีอยู่จริง (เช่น บทความที่ AI แต่งขึ้น) |

## 4. ข้อสรุป (5 คะแนน)

| คะแนน | เกณฑ์ |
| --- | --- |
| 5 | ข้อสรุปตามมาจากผลโดยตรง ระบุข้อจำกัดของงานตัวเองอย่างซื่อสัตย์ |
| 4 | ข้อสรุปสอดคล้องกับผล แต่ไม่ได้ระบุข้อจำกัด |
| 3 | ข้อสรุปกว้างกว่าที่ผลรองรับ |
| 2 | ข้อสรุปแทบไม่เกี่ยวกับผลที่แสดง |
| 0 ถึง 1 | ไม่มีข้อสรุป |

## กรณีที่คะแนนอยู่ระหว่างสองระดับ

ให้คะแนนต่ำกว่า แล้วอธิบายในช่องเหตุผลว่าต้องเพิ่มอะไรจึงจะได้ระดับถัดไป
ข้อเสนอแนะที่บอกวิธีขึ้นระดับ มีค่ากับนักศึกษามากกว่าตัวเลขคะแนน
