## 3. กฎสามประการ

ตรวจว่าระบบของคุณมีครบทั้งสามข้อพร้อมกันหรือไม่

| ข้อ | มีไหม | รายละเอียด |
| --- | --- | --- |
| A. เข้าถึงข้อมูลส่วนตัวหรือข้อมูลอ่อนไหว | | |
| B. รับข้อมูลจากภายนอกที่ควบคุมไม่ได้ | | |
| C. สื่อสารออกนอกได้ | | |

**ถ้าตอบว่ามีครบทั้งสามข้อ ระบบของคุณเสี่ยงต่อการรั่วไหลของข้อมูลโดยไม่ต้องมีการเจาะระบบใด ๆ**
